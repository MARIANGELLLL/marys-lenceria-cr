# MARYS LENCERÍA CR

### Tienda virtual de lencería femenina

MARYS LENCERÍA CR es un emprendimiento costarricense dedicado a la comercialización de lencería femenina. Este proyecto consiste en el desarrollo de una tienda virtual para ofrecer una experiencia de compra sencilla, accesible y adaptable a diferentes dispositivos.

## Objetivo del proyecto

Desarrollar una plataforma de comercio electrónico que permita presentar productos, consultar sus características y facilitar el proceso de compra en línea.

## Tecnologías utilizadas

- HTML5: estructura del sitio web.
- CSS3: diseño y estilos visuales.
- JavaScript: interactividad y funcionalidades.
- WordPress: gestión del contenido.
- WooCommerce: gestión de la tienda virtual.
- Git y GitHub: control de versiones y almacenamiento del código.

## Implementación en WordPress

El proyecto incorpora un tema hijo personalizado llamado Marys Lencería CR Child, basado en Twenty Twenty-Five.

Su finalidad es permitir la personalización del diseño y la estructura del sitio sin modificar directamente los archivos del tema padre.

## Funcionalidades previstas

- Presentación de la marca.
- Catálogo de productos.
- Información de productos y tallas.
- Carrito de compras.
- Proceso de finalización de compra.
- Gestión de pedidos.
- Diseño adaptable a dispositivos móviles.

## Control de versiones

El proyecto utiliza Git y GitHub para mantener un historial de modificaciones, respaldar los archivos y facilitar el seguimiento del desarrollo.
